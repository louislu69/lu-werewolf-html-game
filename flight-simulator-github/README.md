# Claude Flight Simulator

A single-file WebGL Boeing 737 flight simulator prototype.

## Play

Open `index.html` in a desktop browser.

## Controls

- `Shift` / `Ctrl`: throttle up / down
- `W` / `S`: pitch
- `A` / `D`: roll / turn
- `F`: flaps
- `G`: landing gear
- `B`: brake
- `N`: navigation target
- `P`: autopilot
- `R`: reset

## Notes

This project is an experimental browser game. It is designed for desktop keyboard or gamepad play.
