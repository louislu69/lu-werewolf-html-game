# 狼人公寓

2D browser game version of Werewolf Apartment.

## Play

Open `index.html` in a desktop browser, or enable GitHub Pages for this repository.

## Files

- `index.html` - the full 2D game in one HTML file

## Notes

This upload contains only the 2D Werewolf Apartment game. It does not include the flight simulator or the 3D prototype.
